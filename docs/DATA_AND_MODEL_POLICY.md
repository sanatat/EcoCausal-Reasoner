# Data, models and provenance policy

## Included in this repository

- `data/demo_*.json*` and `results/*` examples are authored **synthetic fixtures**, not environmental measurements, not peer-reviewed evidence, and not independent evaluation data.
- Code, unit tests, configuration, reusable protocols and descriptions of unverified optional integration points.

## Excluded from GitHub by default

- Downloaded paper PDFs, images and licensed full text, private documents, access tokens, model checkpoints, Ollama weights, vector indexes, caches and local evaluation databases.
- Any third-party data whose publication terms have not been verified.

## For legitimate real-data work

Record title/DOI/URL, provider, acquisition date, license, consent or access basis as applicable, original SHA-256, preprocessing decisions, annotation author and split before evaluation. Separate retrieved source text from model-generated interpretations. Do not upload files simply because they were available to download.

## Scope of experimental claims

Offline synthetic results establish that some software paths run. They do not establish useful scientific retrieval, real causal identification, LLM reliability, or production readiness. Model weights and real-data evaluations must be executed and reported separately before making such claims.
